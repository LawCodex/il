# הודעת מנהל בתי המשפט בדבר הגשת ראיות במדיה אלקטרונית או דיגיטלית

## לפי תקנות סדר הדין האזרחי, התשע״ט–2018

[י״פ תשפ״א, 2340](https://olaw.org.il/yalkut/yalkut-9309.pdf "הודעת מנהל בתי המשפט בדבר הגשת ראיות במדיה אלקטרונית או דיגיטלית").

***הודעת מנהל בתי המשפט בדבר הגשת מוצג וידאו כראיה הוחלפה (י״פ תשפ״א, 2340) הוחלפה בהודעת מנהל בתי המשפט בדבר הגשת ראיות במדיה אלקטרונית או דיגיטלית (י״פ תשפ״ד, 7695), שהוחלפה בהודעת מנהל בתי המשפט בדבר הגשת ראיות במדיה אלקטרונית או דיגיטלית (י״פ תשפ״ו, 1800).***

בתוקף סמכותי לפי תקנות 71 ו־175 לתקנות סדר הדין האזרחי, התשע״ט–2018, אני מורה כי בעל דין המבקש להציג כראיה לפני בית המשפט מוצג במדיה אלקטרונית או דיגיטלית, יגישו באחד הפורמטים האלה:

### 1.

הגשת ראיה של שמע במדיה אלקטרונית או דיגיטלית:

(א) Windows Media Audio (.WMA)‎;

(ב) MPEG Audio Layer III (.MP3)‎;

(ג) MPEG Audio Layer II (.MP2, .MPA)‎;

(ד) Audio for Windows (.WAV)‎;

(ה) MP4 Audio File (.M4A)‎;

(ו) Windows Audio File (.AAC, .ADT, .ADTS)‎;

(ז) CD Audio Track (.CDA)‎.

### 2.

הגשת ראיה של וידאו במדיה אלקטרונית או דיגיטלית:

(א) Windows Media Video (.WMV, .WM)‎;

(ב) Audio Visual Interleave (.AVI)‎ *[צ״ל: Audio Video Interleave]*;

(ג) MPEG-1 (.MPEG, .MPG, .M1V)‎;

(ד) QuickTime Movie File (.MOV)‎;

(ה) MP4 Video File (.MP4, .M4V, .MP4V, .3G2, .3GP2, .3GP, .3GPP)‎;

(ו) MPEG-2 TS Video File (.M2TS)‎;

(ז) Matroska Video File (.MKV)‎.

### 3.

הגשת ראיה של תמונה במדיה אלקטרונית או דיגיטלית:

(א) Joint Photographic Experts Group (.JEPG, .JPG, .JFIF, .JPE)‎;

(ב) Tagged Image Format (.TIFF, .TIF)‎;

(ג) Graphics Interchange Format (.GIF)‎;

(ד) Windows Bitmap (.BMP, .DIB, .RLF)‎ *[צ״ל: ‎.RLE]*;

(ה) Icon Files (.ICO, .ICON)‎;

(ו) Portable Network Graphics (.PNG)‎;

(ז) HD Photo Files (.WDP)‎.

הודעת מנהל בתי המשפט בדבר הגשת מוצג וידאו כראיה לפי תקנות הסדר האזרחי, התשמ״ד–1984, מיום כ״ט בסיוון התש״ף (21 ביוני 2020) *(י״פ תשע״ג, 240)* – בטלה.
