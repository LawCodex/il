# צו ההגנה על הצומח (מחלות ומגפות) (עשבים רעים), תשי״ג–1953

## צו המכריז על עשבים רעים כעל מגפה לצרכי הפקודה

[ק״ת תשי״ג, 1429](https://olaw.org.il/takanot/takanot-0389.pdf "צו ההגנה על הצומח (מחלות ומגפות) (עשבים רעים)").

בתוקף סמכותי לפי סעיף 4(א) לפקודת ההגנה על הצומח (להלן – הפקודה) והסעיפים 14(א) ו־2(ד) לפקודת סדרי השלטון והמשפט, תש״ח–1948, אני מצווה לאמור:

### 1. עשבים רעים

העשבים הרעים המפורטים להלן הם מגפות לצורך הפקודה:

איסטיס מצוי / Isatis aleppica

אמיתה קיצית / Ammi visnaga

בקבוקון מקומט / Rapistrum rugosum

ברקן סורי / Notobasis syriaca

גדילן מצוי / Silybum marianum

גזר זהוב / Daucus aureus

דבקה משולשת / Galium tricorne

דבשה הודית / Melilotus indicus

דורת ארם צובא / Sorghum halepense

דרדר קפח / Centaurea Verutum

זון משכר / Lolium temulentum

חבלבל השדה / Convulvulus arvensis

חבלבל שעיר / Convulvulus hirsutus

חוח עקוד / Scolymus maculatus

חפורית מוזרה / Phalaris paradoxa

חפורית מצויה / Phalaris brachystachys

חרדל שדה / Sinapis arvensis

טוריים מצויים / Diplotaxis erucoides

כרוב שחור / Brassica nigra

מעוג אפיל / Lavatera trimestris

נורית השדה / Ranunculus arvensis

נירית הקמה / Ridolfia segetum

סבונית השדה / Vaccaria segetalis

סלק מצוי / Beta vulgaris

צלע השור החרוזה / Bupleurum suboratum

צנון מצוי / Raphanus raphanistrum

קחון החוף / Anthemis Leucanthemifolia

קחונית מעורבת / Ormenis mixta

קרדומית השדה / Securigara securidaca

שלמון סורי / Cephalaria syriaca

### 2. השם

לצו זה ייקרא ”צו ההגנה על הצומח (מחלות ומגפות) (עשבים רעים), תשי״ג–1953“.

י״ב באלול תשי״ג (23 באוגוסט 1953)
